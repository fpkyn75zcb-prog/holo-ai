# HOLO AI

GitHub Pages starter. Uses Three.js (MIT) and browser voice and camera APIs.

## Current features
Procedural stylized 3D face with rotation and idle motion; approximate mouth movement during spoken browser responses; optional microphone recognition; camera preview with explicit permission, flip and off; typed chat.

## Limitations
This is not yet a photorealistic rigged head. Replies are scripted, not produced by an AI model. Camera frames are not analyzed. Speech recognition support varies and may use a browser vendor service. No private API keys belong in GitHub Pages source.

## Deploy
Settings → Pages → Deploy from a branch → main → /(root) → Save. Then open https://fpkyn75zcb-prog.github.io/holo-ai/ after publishing.
